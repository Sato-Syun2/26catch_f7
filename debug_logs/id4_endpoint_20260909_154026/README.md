# ID4 増加側端探索（2026-09-09）

対象はRoboMaster ID4のみ。校正後、通常速度制御で+40mm/sを指令。
探索用ファームはCAN送信直前にも±1Aに制限する。ID1は動かしていない。

- 開始位置: -0.396454 mm
- 記録最大位置: 500.688324 mm
- Disable時位置: 500.687988 mm、速度0 mm/s
- 記録最大絶対速度: 45.5125 mm/s
- 記録最大絶対実測電流: 1.195 A（指令上限1Aと実測電流は異なる）
- 既知可動位置として提示された513.353 mmより12.665 mm手前で停止。

feedback.csvとmetadata.jsonを参照。停滞は確認したが、障害物・校正基準差・
機械端の区別は未確定。500.688mmを確定した機械端として採用していない。
シリアルのENDPOINT行は取得できておらず、F7停止原因のログ確認は未完。

継続時の読取ではID4が34.4982mm・速度0・Disable、ID1もDisableだった。
F7のid4_survey_stoppedは0、contact_positionはNaNで、試験終了時と状態が異なる。
リセットや手動移動等の有無を確認するまで追加駆動しない。

現在のソースは一回限りの探索用（id4_endpoint_survey=true）。通常運転用の
50..450mmガードを探索処理に置き換えている。再起動すると探索状態は初期化される。
端位置に基づく恒久的な通常運転用保護への置換は未完了。
