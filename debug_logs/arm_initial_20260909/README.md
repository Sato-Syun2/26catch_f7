# アーム初期同定 2026-09-09

目的はID1（肘）/ID2（根本）のF7電流直接制御DOB＋位置MPC。
MPCはまだ追加していない。既存Mode4 VEL_DOBはモーター側を電流モードにして
F7で電流を計算しiq_refへ送る。内蔵速度制御試験は比較用のみ。
片軸DOB試験の固定側は当面内蔵位置制御。最終構成の両軸MPC保持ではない。

## 実機・設定

- 両軸0度が伸展。起動時のみ±180度正規化を維持し、その後はwrapしない。
- 要求可動範囲は双方-145..145度。位置指令の範囲外を拒否してラッチ。
- 新着Type17 mechPosを専用キャッシュで取得し、Enable前・運転中に範囲/50ms鮮度を確認。
- 運転中異常は再起動までラッチしDisableを要求。失敗時は再試行。
- この監視は端に到達する前の制動距離保証ではない。高速度化前に制動包絡を設計する。
- topicだけで自動Enableしない。明示的なEnable serviceが必要。
- モーター側上限2A、位置速度制限15deg/s。通常運転の目標はユーザー指定5A。
- 今回のDOBはさらにF7ソフト上限1A。5Aへはまだ上げていない。
- RoboMaster両台はarm_test_config.hのARM_TEST_DISABLE_ROBOMASTER=1で
  校正/Enableを拒否し、周期CAN送信もゼロ電流のみ。両台のEnable拒否を実機確認。
  元のRoboMaster制御ゲイン/MPCは保持。
- USB LAN用に既存catch2026-f7を複製しcatch2026-f7-arm-usblanを作成。
  enx9c69d38fde8dへ192.168.5.100/24。元のプロファイルは変更なし、自動接続なし。

- 肘J=0.121497、Kp=5、Ki=1、Ktau=0.94。
- 両軸d=0.02、Kd=0、電流上限1A。JはCAD仮値、dは未同定。
- Ktauは公称Arms値を仮置き。iqとの実効換算/摩擦/荷物/姿勢依存は未同定。
  根本 https://robstride.com/products/robStride02
  肘 https://www.robstride.com/products/eduLite05
- 根本の生速度FBは静止位置でも大きく揺れるため、DOB入力はmechPos差分＋40ms一次LPF。
  生速度FBはROSにそのまま残す。新着位置時刻でのみ差分更新、周期呼び出しによる架空微分なし。
- 制御呼び出しは既存2ms周期。実通信/新着FB500Hzを保証するものではない。
