# ID4 DOB振幅比較（2026-09-09）

実機測定完了。各回250mmに位置制御で復帰した後、速度DOB（ROS mode=4）で1.5～10Hz、60秒の対数チャープを実行。振幅20、200、800mm/s。各回の前後2秒は速度指令0。指令公称100Hz、FB約100Hz。電流制限4A。F7側50mm以下／450mm以上でDisableする一時ガード維持、PC側は80～420mm内を監視。800mm/s試験はFB途絶50msと速度モード逸脱でも中止する設定。ガードは今回発動せず、境界越えの実地試験はしていない。

基準はG(s)=10/(s+10)、時定数0.1秒。ROS受信時刻とその時点の最新送信指令から再構成した外部モデルであり、F7内部モデル状態そのものではない。時刻ずらしによる最適化なし。

200mm/sでは基準モデルに比較的近い。800mm/sでは振幅低下と追加位相遅れが見られ、同じ一次遅れへの一致は悪化した。20mm/sは小振幅に対する速度のばらつきが相対的に大きい。実測電流が4Aに達しなかったことだけでF7内部の出力飽和がないとは断定できない（内部飽和フラグ未記録）。原因切り分けやゲイン変更は未実施。

frequency_response.pngはWelch法による近似FRF。チャープ端点付近、特に約8.5～10Hzは推定コヒーレンスが低く、低信頼区間のゲイン／位相は非表示。通信遅延や時刻誤差も含むため、制御器単体の伝達関数とは区別する。

生データと各回条件のパスはsummary.json内。各測定ディレクトリにfeedback.csv、metadata.json、analysis.json、dob_response.pngがある。
