# Robstride DOB下段の速度誤差PI調整（2026-09-09）

採用値: ID1（肘/EL05）Kp=14, Ki=20、ID2（根本/RS02）Kp=12, Ki=12。Kdは双方0。
設定箇所は `Core/Src/can_devices.c` の configure_robstride_1 / configure_robstride_0。
この値はモーター内部の電流PIではない。

速度誤差 e = omega_model - omega_measured [rad/s] に対し、
電流へのPI寄与は (Kp*e + Ki*integral(e dt))/K_tau。
このほかモデル加速度FFとDOB補償が加算される。Kpは Nm/(rad/s)、Kiは Nm/rad の設定単位。
公称K_tauは肘0.94、根本1.22 Nm/Arms。iq_refとの厳密な電流単位対応は未校正。

## 固定条件と確認範囲

- 制御周期2ms、速度FBのLPF40ms、Q帯域3rad/s。
- 基準モデル時定数は肘0.1s、根本0.2sのまま。JもCAD由来の肘0.121497、根本0.607のまま。
- 内部電流PIは双方 cur_kp=.17, cur_ki=.012, filter_cur=.10 のまま。
- 実験用5A/3A制限を解除し、iq_ref仕様上限の肘11A/根本16Aを有限クランプとして維持。
  モーター側limit_curの11A/16A readbackは arm_pi_candidate_boot.jsonl の最新起動部分で確認。
  ファイル冒頭には旧起動ログも含まれる。RS02の相電流23Apkをiq_ref上限と混同しない。
- 設計角振幅±5°、60秒の対数チャープ＋前後各5秒の包絡。肘0.2–1.5Hz、根本0.2–0.8Hz。
  角度に対して基準モデルの逆補償をした速度入力。任意のステップ応答の最速性を証明する試験ではない。
- 単軸ずつ測定、他軸はPP保持。RoboMaster双方Disable、起動校正無効。
- 実機姿勢は肘約−88〜−91°、根本約105〜111°。全姿勢・同時駆動での最適ゲインとは主張しない。
- DOB RAMログは50Hz、実制御500Hz。電流波形は電流指令とType2トルク/Kt参考値で、iqf実測ではない。

## 比較と採用理由

| 根本・採用再測定 |12/12|201437|1.002|0.0943|1.497|

低周波比は0.5Hz未満の中央値。複素誤差は実位置の周期フィットから速度の振幅・位相を求め、
肘1.3Hz以下/根本0.79Hz以下を1/f加重した abs(actual/model - 1)。
基準の肘5A飽和の影響を避けて共通帯域を選定しているが、旧試験と電流上限・測定姿勢は同一ではない。

肘20/20は移動中の追従が良くてもゼロ速度指令後に約0.7°の往復が残るため不採用。
14/20は停止指令1秒後から4秒間で位置幅0.110°、電流指令RMS0.0573A。
旧20/1比で複素追従誤差は約32%低減。一方、フィルタ速度の時間領域RMSEは3.02→3.56deg/sで改善していない。
採用理由は低周波追従と停止振動の折り合いであり、全指標改善ではない。
根本12/12は低周波振幅比を改善するが全帯域誤差は旧値とほぼ同等。
速度制御なので最終位置ドリフト（肘約−2.25°、根本初回約−1.54°）は残る。位置保持の検証とは異なる。
根本再測定は停止指令1秒後から約4秒間で位置幅0.264°、電流指令RMS0.115A。
再測定の最終位置ドリフトは−3.35°。姿勢・摩擦等によるばらつきが残り、精密位置保持には外側の位置制御が必要。
