# ID1 +90度中心、10Hz拡張試験（途中中止）

2026-09-09。ID1通常PPで+89.76度へ移動後、DOBモード4で測定。
中心移動ログ: ../arm_step_20260909_215107/。
中心移動はPP位置指令で到達を確認。既存limit_spd=15deg/sをPPの速度制限と見なせないため、
以後の中心移動スクリプトには別途15deg/sの位置指令ランプを追加した（追加ランプの実機試験は未実施）。

## 条件

- ID1 Kp14/Ki20、tau0.1秒、Q3rad/s、速度LPF40ms、500Hz制御。
- 電流指令は仕様上限11A。ID2は16AでPP保持、RoboMaster双方Disable。
- DOB入力上限を180→600deg/sへ変更、Debug/Releaseビルド、書き込みverify済み。
- この回は段階確認として入力振幅上限120deg/s。600deg/s試験へは進んでいない。
- 0.5→10Hz・60秒、前後各5秒包絡を予定。低周波側は基準モデルの角振幅約±5度となるよう入力を増加。
- 600deg/sは外部速度入力の上限であり、時定数0.1秒を通ったモデル速度や実速度600deg/sを意味しない。
- 試験開始位置からの変位10度、絶対角±145度、FB途絶を監視。

## 実測結果

- 開始: ID1 +89.756度、ID2 +131.418度。
- 約2.623HzでID1 +79.601度（開始から−10.155度）、ROS速度−82.75deg/sとなり変位ガードで中止。
- 2.2Hz付近から11A指令飽和が発生。2.48Hz局所窓の飽和サンプル率約7.4%（RAM50Hz計測）。
- ピーク: 入力119.99deg/s、モデル69.50deg/s、制御用LPF速度87.50deg/s、ROS Type2速度128.56deg/s。
  ROSピークは瞬時値であり、正弦追従速度振幅ではない。
- 約2.48Hzの位置基本波から計算した速度振幅71.34deg/s、モデル比約1.10。
- 両軸Disableサービスは成功。Disableは能動制動ではなく、慣性による移動が残った。
- 最終FB: ID1 +63.97度、ID2 +139.17度。全ROS記録の角度範囲はID1 63.94〜93.31、ID2 129.59〜139.64度。
- 38個の完全な1秒窓でID1目標/Type2各500、最大制御間隔2ms。
  ring_overrun/priority_full/tx_errors/can_errorsは0。通信停止・クラッシュを示す記録ではない。

10Hz・600deg/sの追従確認は未完了。追従ずれには位置ドリフト・電流飽和が含まれ、
この中止だけで制御系の不安定性や物理最高速度を断定しない。
ID2が上限付近のため追加測定は中止した。次回は根本の保持と中止時の制動/停止距離を先に対処する。
