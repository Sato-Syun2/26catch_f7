# 肘 DOB・FF・PI 再調整

基準: ID1、60 deg/s、0.5–10 Hz 対数チャープ30秒、位相90度。
初期姿勢は根本0度、肘90度への低速移動後。Disable後のずれは各測定metadataに記録。
絶対角度±145度の保護を維持し、RoboMasterは無効。

変更前: P=14, I=20, J=0.121497, d=0.02, Q=3 rad/s,
モデル時定数0.1秒、速度FB LPF 40ms、電流指令上限11A。
baseline.tar.gz は変更前のソースとDebug ELFを保存したもの。
実電流iqfとType2トルク/Ktは区別する。現行DOBログの電流FBは後者。
評価にはフィルタ後速度だけでなく、未フィルタType2速度と位置由来速度を使う。
