# ID4高速速度DOBの調整結果（2026-09-09、実験途中）

対象はRoboMaster ID4のみ（C610/M2006、出力軸99mm/rev、減速36:1）。電源はユーザー申告で6S 5200mAh 50C LiPo、35Aヒューズ。ID1のゲインや電流上限は変更していない。再書き込み時にもID1を動かさないため、試験中はID1の起動自動校正を抑止している。

## 現在書き込み済みの候補

- ID4速度DOBのみ: current_limit=10A、reference_alpha=20/s（時定数0.05s）、velocity_kp=0.1、velocity_ki=1、velocity_kd=0。
- J=0.001、d=0.01、K_tau=1、DOB帯域20/sは従来値。velocity_unit_to_rad_s=1のため、これらを実物のSI慣性・摩擦として解釈しない。
- 位置制御/校正は電流上限4A、既存の位置・速度PIDを維持。
- 最終試験用FWはID4 DOBの指令を±800mm/sに制限。
- ID4 DOBの予測境界判定: 正方向 x+0.08v+15>=430mm、負方向 x+0.08v-15<=70mm。発動後は目標速度0へラッチし、|v|<5mm/sが20周期続いた後Disable。負荷変化・電源断等に対する数学的な停止保証ではない。
- ID4 DOBのROS指令タイムアウト時も速度0で減速後Disable。明示的Disableは従来どおり電流0。
- ID4 CAN受信が10msより古いとDisable（古い速度で閉ループ制動しない）。CAN通信断/位置アンラップ異常の実機故障注入試験は未実施。
- 従来の50mm以下/450mm以上のラッチ式ゼロ電流ガードも維持。
- 診断はF7で500Hz、最大512点をRAM記録し、ID4停止後にシリアル送出。最終方式は一行単位UART送信。正常に512点、2ms間隔、欠損0を取得した。

## 実測

すべて初期位置250mm近傍からの短パルス。最新候補での速度/電流はパルス試験であり、連続速度保証ではない。

|パルス条件|最大実速度 mm/s|内部モデルとのRMSE mm/s|電流指令飽和率（全512点）|ゼロ速度指令後の移動量 mm|
|---|---:|---:|---:|---:|
|+400、120ms、tau=.05、6A、Kp=.5|375.83|11.21|13.8%|17.64|
|+400、120ms、tau=.05、10A、Kp=.5|383.21|11.06|13.1%|16.55|
|+400、120ms、tau=.05、10A、Kp=.1|368.13|7.39|1.2%|16.31|
|-600、120ms、tau=.05、10A、Kp=.1|552.70|14.42|5.9%|25.44|
|+800、150ms、tau=.05、10A、Kp=.1|770.96|25.47|8.4%|36.84|

6A試験はシリアル混線で512点中54点欠損。それ以降の3つのKp=.1試験は全512点正常。飽和率は停止後の区間を含むため、加速中だけの飽和率ではない。加速度の22ms平滑化観測ピークは+800試験で約17,393mm/s²だが、機構の保証加速度や定格ではない。

Kp=.5では電流が正負10A近くまで振動した。上限6→10Aだけでは改善せず、Kp=.1への変更で振動・飽和・誤差が低減した。

## チャープによる追加検証

800mm/s振幅、2～10Hz、30秒、tau=.05、10A、Kp=.1で完走。位置250.18～367.63mm、最大実測電流7.63A、最大実速度691.21mm/s。ROS FB約100Hz、最大受信間隔14.98ms。外部再構成モデルとのRMSE47.67mm/s、モデルRMS342.18mm/s（比13.9%）。

2～5Hzの実測速度RMS403.19、モデル402.23mm/s。5～10Hzは実測221.12、モデル240.80mm/sで減衰と追加位相遅れあり。元のtau=.1、4A、Kp=.5による800mm/s試験とは周波数/時間条件が異なり、誤差率だけで厳密な同条件比較とはしない。

MPCの候補モデルは G(s)=20/(s+20)。10ms離散化では v[k+1]=0.81873075v[k]+0.18126925u[k]。ただし無制約の速度反転、連続最高速、低周波/DC精度、任意負荷に対して検証済みではない。全帯域完全一致/機構限界の特定は未達。MPCには速度/加速度/停止距離の制約が必要。

## 最終確認を中断した理由

最後の安全機能追加FWはDebug/Releaseビルド、書き込み照合まで成功。境界判定の純粋C単体テストは通過したが、境界接近/指令途絶の実機試験は未実施。

最後の再起動後、ID4校正が完了せず、移動スクリプトは初期位置約-250mmを検出して中断しDisableした。以後モーターへの移動指令は出していない。GPIOAをリセットなしHOTPLUGで読み出したところ IDR=0xA026、PA4(sensor2)=LOW。現在の校正コードはPA4=HIGHを校正完了条件にしている。GPIOは入力・プルアップ設定。センサ故障/接触/極性/実際の押下状態はまだ切り分けできていない。校正極性や位置オフセットを推測で変更していない。

停止後FB: ID4 position=-246.45mm、velocity=0、state=0。ID1 velocity=0、state=0。位置は校正未完了の相対値であり、機械の絶対位置として使わない。次はID4の原点スイッチ実押下状態とPA4信号を確認してから校正を再開する。現時点では最終FWをMPC運用完了版と扱わない。
