# チャープからのステップ換算と実測値表

既存ログのオフライン解析のみ。新たなステップ動作・モーター操作は行っていない。

## ステップ応答の表示

[ステップ換算図](estimated_step_responses.png) / [数値CSV](estimated_steps.csv) / [同定パラメーター・誤差](step_estimation.json)

現在の肘DOBの基準一次遅れは G(s)=1/(0.1s+1)。速度ステップ振幅をVとすると、
理想応答は v(t)=V*(1-exp(-t/0.1))。0.1秒で63.2%、約0.30秒で95%、約0.46秒で99%。
黒破線はこの理想応答で、実測チャープで記録した目標モデルと同じ時定数。

チャープのType2未LPF速度/入力の局所周波数応答を、因果的FIRモデルに近似してステップ換算。
FIRは20ms×76タップ。直流ゲイン1、最初と最後のタップ0を制約し、
未測定帯域の影響を抑えるため理想モデルのインパルス応答を事前値とした正則化を使用。
標準lambda=10、lambda=1〜100の結果の範囲を色帯で表示。色帯は統計的信頼区間ではない。

重要な制約:

- 実測ステップではない。最終的に目標値へ一致するのは制約として仮定した結果で、実測の定常偏差を示さない。
- 10Hz以上が未測定なので、最初の約50ms（灰色背景）の形は特に信頼できない。
- 60/120の使用帯域は0.734〜9.5Hz、400は2.3〜9.5Hz。低周波・直流の挙動は未同定。
- 400は指令飽和サンプル率62.5%の強い非線形動作で、LTI近似による大振幅ステップ予測は有効と扱えない。
  図が理想応答に近く見えるのは未測定低周波への事前仮定の影響であり、優れた追従を示さない。
- 60/120についても、正則化による近似誤差と低周波未測定がある。図から実際の整定時間やオーバーシュートを断定しない。
- 周波数応答への相対複素RMS近似誤差は60:20.5%、120:16.0%、400:18.7%。
  [測定FRFと近似モデルの比較](step_fit_validation.png)を併記。

## チャープ実測の目標・速度・参考電流

[実測時系列図](measured_chirps_and_current.png)は、列が60/120/400、上段が全30秒、
中段が最初の3秒拡大、下段が参考電流と電流指令。中段もチャープであり、ステップではない。

参考電流 = Type2トルク / 公称トルク定数0.94 Nm/Arms。
Arms相当の参考値であり、iqfを直接読み出した実測電流ではない。
電流指令11Aと参考電流5Aを単位・推定過程を無視して比較し、電流追従が半分だと判断しない。

| 入力速度振幅 | 周波数Hz | 実速度範囲 deg/s | 実速度RMS deg/s | 参考電流範囲 Arms相当 | 参考電流RMS Arms相当 |
|---|---|---|---|---|---|
|60deg/s|0.5〜10|−87.82〜92.28|30.66|−3.329〜3.367|1.095|
|120deg/s|0.5〜10|−166.42〜147.10|61.96|−5.254〜5.047|2.188|
|400deg/s|2〜10|−319.50〜341.89|110.87|−5.154〜5.308|3.125|

全て掃引30秒区間の集計。実速度はType2の未LPF速度なので瞬時ノイズ・高調波を含み、
範囲の最大値は正弦波基本波振幅でもステップ時のオーバーシュートでもない。
400だけ周波数範囲が異なるため、全区間RMSをそのまま線形性の指標にしない。
