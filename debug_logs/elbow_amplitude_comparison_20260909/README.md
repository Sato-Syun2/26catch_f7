## 正規化と一貫性

時間を伸縮して比較するのではなく、各ログから同じ周波数の局所基本波を抽出し、速度応答/入力を求めた。
グラフの速度振幅は、この伝達比に60deg/sを掛けて同じ入力振幅相当に正規化。
400deg/sの2Hz未満のデータは存在せず、補完・外挿していない。
完全な4周期窓のみ使用するため、3条件の数値比較帯域は約2.3〜9.5Hz。

- [未LPF Type2速度の比較](raw_velocity_comparison.png)
- [位置由来速度・モデル比・電流飽和・角振幅](amplitude_comparison.png)
- [比較数値](amplitude_comparison.json)、[試験集計](test_summary.json)

未LPF Type2速度で60deg/sを基準に比較した結果:

| 条件 | 正規化ゲイン比中央値 | ゲイン比範囲 | 位相差絶対値中央値 | 複素応答差の相対値中央値 |
|---|---|---|---|---|
|120deg/s|1.043|0.924〜1.161|5.37度|0.132|
|400deg/s|0.830|0.301〜1.099|21.76度|0.460|

60と120は比較的近いが完全一致ではない。400は特に2〜4Hzで強い指令飽和と応答低下があり、
全速度域を単純な振幅スケーリングで同じモデルに重ねることはできない。
約2.45Hzの400試験では実速度基本波振幅約73deg/s、指令飽和サンプル率約90%。
約9.5Hzでは実速度基本波振幅約154deg/s（入力400deg/s）。瞬時ピーク速度約342deg/sを
「400deg/sの正弦波に追従した」と解釈しない。

加えて高周波では、制御器が見る40ms LPF後の速度と未LPFの実速度は異なる。
60/120でも高周波の実速度はtau=0.1秒の理想応答と一致していない。
小振幅・バックラッシュ・高調波・掃引速度の違いも含むため、一貫性の差をPIだけの問題と断定しない。
120の最低周波数帯の大きな角変位や、400試験での姿勢ドリフトも比較条件の限界。
